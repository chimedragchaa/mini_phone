# Mega Phone — холболт, код, шалгах дараалал

Энэ хавтас нь Arduino Mega 2560, 2.8 инчийн TFT touch/SD shield, SIM800L болон PAM8403 ашиглаж буй утасны төслийн ажлын файлууд юм. `sources/` хавтасны төслийн хуулбарыг өөрчлөөгүй.

## Файлууд

- `phone_app/phone_app.ino` — үндсэн firmware: дуудлага хийх/авах, дуудлагын түүх, харилцагч, SMS, SD зураг ба хөгжим.
- `codex_phone.ino` — TFT, touch, SD картыг тусад нь шалгах sketch.
- `touch_calibration/touch_calibration.ino` — touch дэлгэцийн тохируулгын sketch.
- `CONTACTS.CSV` — харилцагчийг компьютерээр урьдчилж оруулахад зориулсан загвар; утасны дэлгэцээс `ADD` дарж үүсгэж бас болно.
- `tools/wav_to_raw.py` — WAV файлыг Mega дээр тоглуулах форматаар хөрвүүлэх хэрэгсэл.
- `phone-ui-preview.svg` — UI загварын урьдчилсан зураг.

## Одоогийн шалгалтын байдал

Шинэ firmware COM35 (CH340) дээр compile, upload, verify амжилттай. Асаалтын serial шалгалтаар SD `card ready`, SIM `READY`, сүлжээний бүртгэл `1,1`, тухайн агшинд `CSQ 17–18` гэж ирсэн. Өмнөх нэг шалгалтад `CSQ 15` байсан тул хөдөлгөх үеийн хэлбэлзлийг тусад нь ажиглах шаардлагатай. Асаахад `CONTACTS` 0 бүртгэлтэй, `CALLS.CSV` файл хараахан байгаагүй. SD картаа firmware форматлахгүй.

## Firmware upload хийх

VS Code-ийн PowerShell terminal-д төслийн үндсэн хавтас (`codex_phone`) дээрээс дараахыг ажиллуулна. COM порт өөрчлөгдвөл `COM35`-ийг шинээр илэрсэн портоор солино.

```powershell
arduino-cli compile --fqbn arduino:avr:mega --port COM42 --build-property 'compiler.cpp.extra_flags=-DSPI_DRIVER_SELECT=2' --upload --verify .\phone_app
```

USB Serial Monitor: **115200 baud**. SIM800L UART: кодын одоогийн тохиргоогоор **9600 baud**. SD shield-ийн Uno маягийн D10–D13 утсыг Mega дээр SdFat software SPI-р уншдаг.

## 1-р шат — зөвхөн SIM800L тэжээл ба UART

Mega болон shield-ийн тэжээлийг салгаж байгаад утас холбоно. Одоохондоо PAM8403, микрофон, хөгжимний чанга яригчийг бүү холбо.

1. SIM800L-ийн антенныг холбоод SIM картаа хийнэ. SIM карт PIN нэхдэггүй, дуудлага/SMS ашиглах боломжтой байх шаардлагатай.
2. SIM800L breakout хавтангийн яг ямар загвар, тэжээлийн pin болохыг шошгоос нь хар. Нүцгэн SIM800L модульд **3.4–4.4 V, зөвлөмжөөр 4.0 V орчим, дамжуулах үеийн 2 A гүйдлийн оргилыг даах тэжээл** шаардлагатай. Mega-ийн 5 V pin-д шууд бүү холбо. Зарим breakout өөрийн зохицуулагчтай бөгөөд `5V` гэж тэмдэглэсэн оролттой байдаг; зөвхөн хавтан дээрээ `5V` гэж бичсэн бол тэр оролтыг хэрэглэ. SIM800L үйлдвэрлэгч бага ESR 100 µF орчмын конденсаторыг модулийн тэжээлд ойр байрлуулахыг зөвлөдөг.
3. Гаднын тэжээлийн GND-г Mega GND-тэй холбоно. HW-131 модулийг хэрэглэх бол эхлээд мультиметрээр гаралтын хүчдэлийг хэмж. SIM800L-ийн оролт дээрх зөв хүчдэл, 2 A оргил гүйдлийг хангаж чадах эсэх нь тодорхой болтол бүү залга.
4. Кодын чиглэл зөв: **SIM800L TXD → Mega D19/RX1**, **Mega D18/TX1 → SIM800L RXD**. Харин танай хэлсэнчлэн level shifter байхгүй бол D18-ыг RXD-д шууд залгасан хэвээр бүү ашигла: Mega-ийн гаралт 5 V, SIM800L-ийн UART логик бага хүчдэлтэй. 2.8 V талдаа тохирох level shifter тавь; үйлдвэрлэгч 5 V UART-д түвшин тааруулах схем санал болгодог. Модулийн TXD буцах чиглэлд ч түвшин хувиргагч хэрэглэх нь найдвартай.

   | Mega 2560 | Level shifter | SIM800L breakout |
   |---|---|---|
   | D18 / TX1 | HV тал → LV тал | RXD |
   | D19 / RX1 | LV тал → HV тал | TXD |
   | 5 V | HV reference | — |
   | 2.8 V reference (эсвэл хавтан дээрх VDD_EXT) | LV reference | зөвхөн pin нь ил гарсан бол |
   | GND | GND | GND |

   `VDD_EXT` байхгүй бол өөр 2.8 V reference хэрэглэдэг translator шаардлагатай. Translator-ийн хүчдэл, pin-ийн шошгыг шалгалгүйгээр дур мэдэн холбохгүй.
5. **GND-г нийтлэг холбоно:** SIM800L-ийн тэжээлийн GND болон UART level shifter-ийн GND-г Arduino Mega-ийн GND-тэй холбо. Гаднын SIM тэжээлийн эерэг хүчдэлийг Mega-ийн 5 V pin-д бүү нийлүүл.
6. `RST` нь ердийн асаалт/унтраалтын pin биш, яаралтай reset-д зориулсан **active-low** оролт. Ашиглахгүй бол холболгүй орхи; GND-д байнга бүү холбо, Mega-ийн RESET эсвэл 5 V-д бүү залга. Үйлдвэрлэгчийн SIM800L (MT6261) баримтад reset хийхдээ бага түвшинд 105 ms-аас удаан татахыг заасан. Автоматаар удирдах шаардлагатай үед 5 V GPIO-г RST-д шууд өгөхгүй, түвшин тохирох транзистор/open-drain холбоос хэрэглэ.
7. SIM800L-ийг өөрийн хавтангийн зөв тэжээлээр асаана. `PWRKEY` товчтой бол дарж асаагаад суллана. Serial Monitor-оор модемийн `OK` хариуг шалга. Дэлгэцийн дээд талд `GSM OK` гарвал сүлжээнд бүртгэгдсэн гэсэн үг; `MODEM?`, `SIM?`, `SEARCH` хэвээр бол дараагийн шат руу орохгүй.

SIM800L-ийн жижиг breakout хавтангуудын тэжээл болон RX/TX байрлал ялгаатай. Тиймээс хавтангийн тань зураг, pin-ийн бичгийг харж баталгаажуулахаас өмнө тэжээлийг таамгаар бүү холбо.

## 2-р шат — дуудлагын чанга яригч ба микрофон

Энэ шатанд модем хариулж, сүлжээнд бүртгэгдсэн байх ёстой. Дууны pin нь breakout дээр ил гарсан тохиолдолд холбоно.

- 8 Ω чанга яригчийг SIM800L-ийн `SPK+ / SPK-` эсвэл `SPK2P / SPK2N` хос pin-д холбоно. Хоёр утасных нь аль алийг GND-д бүү холбо. Эхний туршилтад кодын `AT+CLVL=25` дууны түвшнийг хэвээр байлгана.
- SIM800L-ийн `MIC+ / MIC-` эсвэл `MIC1P / MIC1N` гэсэн differential оролтод тохирох хоёр утаст electret микрофоны капсулыг холбоно. Богино утас хэрэглэж, антенн болон SIM тэжээлийн утаснаас зайлуул.
- **Микрофоны тухай өмнөх зааврын тайлбар:** SIM800L-ийн MIC1P/MIC1N оролтыг electret микрофонд зориулсан гэж үйлдвэрлэгчийн баримтад заасан. Миний өмнө “шууд холбоно” гэж хэлсэн нь энэ хоёр утаст капсулыг breakout дээрх `MIC+/-` оролтод холбохыг хэлсэн юм. Харин Arduino mic board-ийн `VCC/GND/AO/DO` нь тусдаа өсгөгч/мэдрэгчийн гаралт байж болох тул түүний `AO` эсвэл `DO`-г SIM800L-ийн differential MIC pin-д шууд залгаж болохгүй. Одоогийн firmware-д `AO`-г зөвхөн A8 дээр өрөөний дууны түвшин хэмжихээр ашиглана; утасны дуудлагын микрофон биш.
- Breakout дээр микрофоны pin байхгүй, эсвэл микрофон хавтангийн төрөл тодорхойгүй бол түүний хоёр талыг зураг аваад эхлээд pin-ийг тогтооно. Шууд solder хийхээс өмнө яг аль нь electret капсул болохыг таних хэрэгтэй.

Дараа нь таньдаг дугаар руу залгаж, гаднаас SIM рүү залган **ANSWER**, **REJECT**, **END CALL** товчийг шалгана.

## Реле хэрэглэхгүй speaker холболт

SIM800L болон PAM8403 хоёулаа чанга яригчийг хос гаралтаар (bridge/BTL) жолооддог. Тэдгээрийн `SPK+/-` ба `L+/-` гаралтыг нэг speaker рүү зэрэгцүүлж холбож болохгүй. Реле хэрэглэхгүй дараах хоёр хувилбар бий:

### Сонголт A — тус тусдаа хоёр чанга яригч

Энэ нь автомат ажилладаг хамгийн энгийн, найдвартай хувилбар. Одоо байгаа 8 Ω speaker-ээ SIM800L-ийн `SPK+/-` дээр дуудлагад холбо. PAM8403-ийн `L+/-` дээр хөгжмийн зориулалттай хоёр дахь speaker холбо. Ингэснээр дуудлага SIM800L-ийн speaker-ээр, SD хөгжмийн файл PAM8403-ийн speaker-ээр гарна; реле хэрэггүй.

### Сонголт B — нэг чанга яригч, гар DPDT switch

Реле биш, хоёр туйлыг зэрэг шилжүүлдэг **DPDT ON-ON toggle/slide switch**-ээр speaker-ийн хоёр утсыг сонголттой залгаж болно. `COM` хоёр contact нь speaker-ийн хоёр тал; нэг байрлалын хоёр contact SIM800L `SPK+/-`, нөгөө байрлалынх PAM8403 `L+/-` байна. Switch нь дор хаяж 1 A contact rating-тэй байг. Дуудлага хийхдээ SIM800L байрлалд, хөгжмөө тоглуулахдаа PAM8403 байрлалд гараар шилжүүлнэ. Код switch-ийг автоматаар удирдахгүй.

### Сонголт C — нэг чанга яригч, switch байхгүй

Одоохондоо туршилтаар speaker-ийн хоёр утсыг зөвхөн нэг төхөөрөмжид холбо. Дуудлага туршихдаа SIM800L `SPK+/-` дээр, SD хөгжим туршихдаа PAM8403 `L+/-` дээр холбоно. Нэгээс нөгөөд шилжүүлэхийн өмнө Mega, SIM800L, PAM8403-ын бүх тэжээлийг салгаж speaker-ийн хоёр утсыг гараар шилжүүл. Энэ аргаар нэг төхөөрөмж дээр л дуу гарна; автоматаар солигдохгүй. Утсыг хөдөлгүүртэй үед салгаж-залгахгүй.

Ганц speaker-ийг автоматаар солих электрон аудио selector хийх боломжтой ч SIM800L-ийн дифференциал speaker дохиог PAM8403-ийн line input-д тааруулан хувиргах тусдаа интерфэйс шаардлагатай. Одоо байгаа эд ангиудаар хоёр speaker эсвэл гар DPDT switch-ээс энгийн аюулгүй холболт гарахгүй. Хоёр өсгөгчийн speaker гаралтыг шууд нийлүүлж болохгүй.

## 3-р шат — PAM8403-аар SD хөгжим тоглуулах

PAM8403-ийг тогтвортой 5 V тэжээлээр ажиллуулж, GND-г Mega-ийн GND-тэй нэгтгэнэ. Mega D46 нь 8-bit PWM дууны эх үүсвэр. Дараах low-pass шүүлтүүр болон оролтын attenuator ашиглана:

```text
Mega D46 ── 4.7 kΩ ──●── (+) 1 µF (−) ── 1 kΩ ──●── PAM8403 L-IN
                      │                           │
                    10 nF                       1 kΩ
                      │                           │
                     GND ──────────────────────── GND ── PAM8403 GND
```

1 µF конденсаторын `+` тал нь PWM шүүлтүүрийн талд, `−` тал нь PAM8403 оролтын талд байна. Speaker-ийг зөвхөн PAM8403-ийн `L+ / L-` дээр холбоно; аль ч speaker гаралтыг GND-д бүү холбо. 8 Ω / 0.5 W speaker тул эхний удаад PAM8403-ийн дууны түвшнийг бага байлга.

## Харилцагч ба мессеж

### Харилцагчийг утаснаасаа нэмэх

1. Үндсэн цэснээс **CONTACTS** → **ADD** дар.
2. **Name** эсвэл **Phone** мөрөнд хүрч тухайн талбарыг сонго. Дэлгэцийн товчлуураар нэр, дугаараа оруул. **123/ABC** нь үсэг/тоон товчлуурыг солино; **DEL** сүүлийн тэмдэгтийг арилгана.
3. **SAVE** дармагц SD картын үндсэн хавтас дахь `CONTACTS.CSV` файлд хадгална. Дэлгэцээс хамгийн ихдээ 8 харилцагч нэмнэ; нэр 12, дугаар 20 тэмдэгтээс уртгүй. Дугаарыг `+976...` гэх мэт олон улсын форматаар, зайгүй оруул.

Компьютерээр урьдчилж оруулах бол FAT32 SD картын үндсэн хавтаст `CONTACTS.CSV` байрлуулаад нэг мөрөнд `Нэр,дугаар` форматаар бич:

   ```text
   Eej,+976XXXXXXXX
   Naiz,+976YYYYYYYY
   ```

   Жишээний X/Y-г жинхэнэ дугаараар солино. Нэрийг 12 тэмдэгтээс, дугаарыг 20 тэмдэгтээс хэтрүүлэхгүй; одоогийн дэлгэцийн фонт кирилл үсэггүй тул нэрийг латинаар бич. Хамгийн ихдээ 8 харилцагч уншина, нэг хуудсанд 5-ыг харуулна.
- **CONTACTS** цэснээс хүнийг сонгоод **CALL** эсвэл **TEXT** дар. **DELETE** дарж, дараагийн баталгаажуулах дэлгэцэд дахин **DELETE** сонгож контактыг SD картын жагсаалтаас устгана. Шинэ контакт `CONTACTS.CSV`-ийн төгсгөлд шууд нэмэгдэнэ. Монгол дугаарыг `+976` угтвартай хадгалсан бол залгахын өмнө `+976`-г авч орон нутгийн дугаараар залгана; зай, зураас, хаалт байвал мөн цэвэрлэнэ.
- Үндсэн цэсний **CALL HISTORY** хэсэг сүүлийн 8 дуудлагын дугаар, орсон/гарсан төрөл, үргэлжилсэн хугацаа, missed/reject/failed зэрэг үр дүнг харуулна. Энэ түүх SD картын `CALLS.CSV` файлд хадгалагдана. RTC цагийн модуль байхгүй тул огноо, цаг хадгалахгүй.
- **MESSAGES** цэс SIM800L-ийн SIM/модемын санах ойноос сүүлийн 5 SMS-ийг уншина. Энэ нь SD картын жагсаалт биш. **REFRESH** дарж шинэчил. Inbox мессежийг нээгээд **DELETE** дарж, баталгаажуулсны дараа SIM800L-ийн SMS санд буй мессежийг устгана.
- Харилцагчийн **TEXT** эсвэл inbox дээрх **REPLY**-г дарж 40 хүртэл ASCII/GSM тэмдэгт бич. **SAVE** нь нооргийг SD картын `DRAFTS.TXT` файлд хадгална. **MESSAGES** → **SAVED** хэсэгт мөрийн баруун талын **DEL**-ээр ноорог устгана; мөрийн бусад хэсгийг товшиж нээх, засах буюу илгээж болно. **SEND** нь SMS илгээнэ; илгээхэд SIM идэвхтэй, сүлжээнд бүртгэлтэй байх шаардлагатай.

## SIM ба сүлжээний төлөвийг өөрөө шалгах

- Дэлгэцийн баруун дээд булан дахь `MODEM? / SIM? / SEARCH / GSM OK` тэмдэг дээр дарж **NETWORK STATUS** дэлгэцийг нээ.
- **CHECK** нь модемд `AT`, `AT+CPIN?`, `AT+CREG?`, `AT+CSQ`, `AT+COPS?` команд илгээж хариуг харуулна. Үүнд модемийн хариу, SIM-ийн төлөв, сүлжээний бүртгэл, дохионы `CSQ` болон операторын нэр орно.
- Сүлжээний дэлгэц нээлттэй үед төлөвийг 5 секунд тутам, бусад дэлгэц дээр 10 секунд тутам асууна. Энэ дэлгэц 2 секунд тутам тухайн үед авсан мэдээллээ зурна. **CHECK**-г дарж гараар дахин шалгаж болно. Дуудлага, inbox уншилт, SMS илгээлтийн үеэр асуулгыг түр завсарлуулна. Модем огт хариу өгөхгүй үед `AT`-г 1.5 секунд тутам дахин шалгана. SIM800L өөрөө сүлжээ хайх ажиллагааг хариуцна.
- **TOUCH CAL** дээр дэлгэцийн зүүн, төв, баруун талын одны голд дарахад хэвтээ тэнхлэгийг тусад нь 3 цэгээр тааруулж EEPROM-д хадгална. Босоо тэнхлэгийн одоогийн тохируулгыг өөрчлөхгүй.
- `Registered (home/roaming)` ба `CSQ` 0–31 байвал бүртгэгдсэн, дохио хэмжигдсэн байна. `Searching`/`Registration denied` эсвэл `CSQ 99` гарвал антенн, SIM PIN/идэвх, операторын 2G GSM хамрах хүрээ болон тэжээлийг шалга. `Modem: No response` бол эхлээд модулийн тэжээл, PWRKEY, GND, UART TX/RX болон түвшин хувиргагчийг шалга.

Одоогийн serial шалгалтаар модем хариулж, SIM ба сүлжээ бүртгэлтэй байна. `MODEM?` гарвал **CHECK** дар; 15 секунд хариу ирэхгүй бол тэжээл болон UART холбоосоо шалга.

### Сүлжээ сулрах үед

- Антенны урд/дээр металл, тугалган цаас, батарей эсвэл shield бүү тавь. Халхлах тусам хүлээн авалт муудна. Антенныг залгуурт нь сайн суулгаж, дэлгэцийн металл ар, PAM8403, USB утас болон чанга яригчийн утаснаас хол байрлуул.
- Антенны төрөл тодорхойгүй бол 50 Ω, 850/900/1800/1900 MHz GSM-д зориулсан зөв залгууртай антеннаар турш. SIMCom нь антенны оролтын импеданс 50 Ω, VSWR 2-оос бага байхыг заасан.
- Хөдөлгөөнөөр тасалдах нь тэжээлийн хүчдэл унахтай холбоотой байж болно. Нүцгэн SIM800L модульд 3.4–4.4 V, ойролцоогоор 4.0 V, богино дамжуулалтын оргилд 2 A хүртэл гүйдэл шаарддаг; 100 µF бага ESR конденсаторыг VBAT-д ойр тавихыг үйлдвэрлэгч зөвлөсөн. Breakout хавтан дээр тусдаа 5V оролт гэж тэмдэглэсэн бол тэр хавтангийн зааврыг дага.
- **NETWORK STATUS** дээр `CSQ`, `CREG`-ийг утсаа хөдөлгөхгүй барьж 20–30 секунд харьцуул. `CSQ 15` нь ойролцоогоор −83 dBm бөгөөд бүртгэлтэй үед боломжийн үзүүлэлт; харин огцом буурч `99` болох эсвэл `CREG` 1-ээс 0/2 руу орвол антенн, тэжээл, орчны саад болон тухайн операторын 2G хамрах хүрээг шалга.

SIM800-ийн `AT+CMGS`, `AT+CMGR`, `AT+CMGL`, `AT+CNMI`, `AT+CPMS`, `AT+CMGD` нь үйлдвэрлэгчийн SMS зааварт тодорхойлогдсон командууд. [SIM800 Series AT Command Manual](https://simcom.ee/documents/SIM800C/SIM800%20Series_AT%20Command%20Manual_V1.10.pdf)

## SD зураг, хөгжим

Файлуудыг картын үндсэн хавтсанд байрлуул:

- `PHOTO.BMP` — шахаагүй 24-bit BMP, хамгийн ихдээ 320 × 178 pixel.
- `SONG.RAW` — header-гүй unsigned 8-bit PCM, mono, 8000 sample/секунд.

WAV хөгжмөө Python 3-аар хөрвүүлэх команд:

```powershell
python .\tools\wav_to_raw.py .\duu.wav .\SONG.RAW
```

Үүссэн `SONG.RAW`-г SD картын үндсэн хавтас руу хуул. Үндсэн цэснээс **MEDIA** → **PHOTOS** эсвэл **MUSIC** руу орно. Дэлгэцийн BMP жишээний суурь нь MCUFRIEND_kbv-ийн SD BMP жишээ. [MCUFRIEND showBMP жишээ](https://github.com/prenticedavid/MCUFRIEND_kbv/blob/master/examples/showBMP_kbv_Uno/showBMP_kbv_Uno.ino)

## Mega pin-ийн товч хүснэгт

| Үүрэг | Mega pin |
|---|---:|
| SIM800L UART (level shifter дамжуулж) | D18 TX1, D19 RX1 |
| Arduino mic board-ийн дууны түвшин AO (сонголтоор) | A8 |
| PAM8403 audio input PWM | D46 |
| Shield SD CS / MISO / MOSI / SCK | D10 / D12 / D11 / D13, software SPI |
| Shield resistive touch | XP=D8, XM=A2, YP=A3, YM=D9 |

Touch-ийн эхний тохируулга кодонд `TS_LEFT=867`, `TS_RIGHT=167`, `TS_TOP=177`, `TS_BOTTOM=953` гэж байна. **TOUCH CAL** ажиллуулсны дараа хэвтээ 3 цэгийн шинэ утгууд EEPROM-д хадгалагдаж, дараагийн асаалтад автоматаар хэрэглэгдэнэ; босоо тохируулга хэвээр үлдэнэ.
